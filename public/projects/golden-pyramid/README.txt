Golden Pyramid Resort Reservation System - Image Guidelines
============================================================

Add 2 images to this folder:
- 1.jpg - System dashboard or reservation calendar
- 2.jpg - Database schema or system workflow diagram

Recommended image specifications:
- Format: JPG, PNG, or WebP
- Aspect ratio: 16:9 (1920x1080 recommended)
- File size: Keep under 500KB for optimal loading
- Quality: High resolution screenshots or documentation images

Images will appear in a carousel on your portfolio website.
