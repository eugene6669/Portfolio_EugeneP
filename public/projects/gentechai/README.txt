GentechAI - AI-Powered Productivity Platform - Image Guidelines
================================================================

Add 4 images to this folder:
- 1.jpg - Main workspace dashboard or homepage
- 2.jpg - AI assistant or tool interface
- 3.jpg - CRM or client management view
- 4.jpg - Browser tools or invoice/tracking features

Recommended image specifications:
- Format: JPG, PNG, or WebP
- Aspect ratio: 16:9 (1920x1080 recommended)
- File size: Keep under 500KB for optimal loading
- Quality: High resolution screenshots

Images will appear in a carousel on your portfolio website.
